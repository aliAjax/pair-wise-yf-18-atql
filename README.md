# hxyfront-62006 珠宝镶嵌派工账本

源提示词编号：8

珠宝镶嵌工作室每天按班组派石。复核结论和保险额度常在派工后才变，白板上的占位就这样失真。本系统把现有分拣页变成**派工账本**：

- 每颗裸石先占用订单石位，再按班组工位容量放入当班队列
- 写入失败后保留待确认回执，重试不得重复占用石位
- 复核结论变化后连带重算相关订单：不再合格的石头退回原批次；工位容量不足时按候补顺序排队；仍放不下显示最早阻塞项
- 每次变动保留前后值、操作人、批次号和重试次数
- 页面可按订单、班组和状态查看

## 结构

规则、存档与页面分开维护：

```
src/
  rules/      规则层：领域类型 + 派工业务规则（纯函数）
  ledger/     存档层：状态管理、localStorage 持久化、账本、演示数据
  components/ 页面层：订单/班组/状态三视图、待确认回执、阻塞项、账本、表单
  App.tsx     页面组合
```
